# Changelog

## 0.1.0

Initial Kite development release.

- Original geometric Kite identity, Paper and graphite surfaces, and a focused welcome screen.
- Native Rust editor with tabs, syntax highlighting, find and replace, atomic saves, and unsaved-change prompts.
- Multiple PTY terminal sessions, quick open, and a command palette.
- Native Markdown and Mermaid previews.
- macOS and Windows installer packaging, checksums, and draft release automation.
- Linux installation from source.

This is early software. See the README for current limits and release notes for each package's signing status.
